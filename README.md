# CS330: Computational Graphics and Visualization

## Overview
This project involved designing and developing an interactive 3D scene in OpenGL, recreating a set of real-world objects through custom shapes, textures, and lighting.

## Approach
I broke the scene down into individual 3D shapes built from primitive meshes, then organized the code with a dedicated SceneManager to handle rendering, navigation, and lighting separately from the main program logic. Working with reusable libraries and utility functions for tasks like loading textures and rendering shapes kept the project organized as its complexity grew.

## Reflection
This project changed how I approach designing software: planning a scene's structure, mapping out which objects, textures, and lighting effects were needed before writing code, made development far more efficient than diving straight in. The design skills I developed here, particularly breaking a complex visual problem into smaller, reusable components, will carry over into future projects that need to be built piece by piece. Working in computational graphics also introduced new development strategies, like iteratively testing how lighting and camera movement affected the scene before adding more complexity, which is an approach I plan to keep using going forward.
